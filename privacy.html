Privacy policy

Last updated: 17 November 2026

Who uses this app

Hermes is a personal app. Its only user is its owner, Nikolaos Savvas. It is not offered to anyone else.

What data it accesses

With the owner's permission, Hermes reads the owner's own Gmail, Google Calendar, Google Drive, Google Docs, Google Sheets and Google Contacts.

How the data is used

The data is used only to help the owner: daily briefs, summaries, reminders and personal record keeping.

Where the data is kept

Data is processed and stored on the owner's own home computer. The sign-in token is stored only on that computer.

Sharing

Data is not sold, shared or transferred to anyone. It is not used for advertising. It is not used to train AI models.

Google API Services User Data Policy

Hermes's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can remove Hermes's access at any time at myaccount.google.com/permissions.
